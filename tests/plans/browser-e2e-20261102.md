# Test Plan: browser-e2e

## Created
2026-11-02

## Goal
요구사항 1~5 와 「자원 제한은 웹 설정으로」를 **화면 조작으로** 확인한다(헤드리스 Chromium, Playwright).
- 1 모델 관리: 미리 지정된 모델 목록·라이선스 배지·확인 상태·위치 지정 버튼·환경 설치 상태
- 2 참조 세트: 업로드 → 자동(ASR) → 동의 없으면 막힘 → 만들기 → 전사문 사람 수정 → 저장·재사용
- 3 TTS: 엔진 파라미터(카탈로그 스키마) 입력 → 생성
- 4 결과: 모든 파라미터와 함께 저장 → 불러오기 = 폼 복원 → 같은 설정으로 다시 만들면 같은 출력(결정적 모의 엔진: 해시 동일)
- 5 ASR: 전사 → 타임라인 구간 클릭 재생 → SRT 내려받기
- 설정: GPU 체크로 허용 카드를 바꾸면 `allowed_gpus` 가 그 uuid 로 저장되고 뺀 카드에 「설정에서 제외」
- 실제 엔진(@gpu): Qwen3-TTS 1.7B 를 웹에서 생성, 결과 장치가 허용 카드 안

## Environment
- 서버: 원격 4080x2(m42-server2) `D:\voice`, `npm run deploy`(VOICE_HOST=0.0.0.0), `http://192.168.0.29:8765`, 모델 `N:\models`
- 브라우저: 개발 PC(hikaTR) Playwright 1.55.1 Chromium headless, `playwright.config.ts`
- 모의 엔진: 시험이 `PUT /api/settings {show_test_engines: true}` 로 켜고 끝나면 되돌린다

## Preconditions
- 원격 엔진 환경 qwen·fwhisper 설치, 모델 qwen3-tts-1.7b-base·fw-large-v3 확인 ok
- @gpu: fw-large-v3 로 만든 자동 참조 세트가 하나 이상

## Steps

VOICE_E2E_BASE=http://192.168.0.29:8765 VOICE_E2E_GPU=1 npx playwright test --reporter=line

## Expected Results
4개 통과. 흐름 시험에서 두 결과의 `output.sha256` 동일, `ref.text` = 사람이 고친 전사문. @gpu 결과 `engine=qwen`, 길이 > 2 s, `device[].uuid ⊂ allowed_gpus`.
